# Changelog

## 1.6.0 - 2026-10-31

- Restore the game's original snapping by removing the patches on snap detection and occupied-voxel availability.
- Remove automatic placement-preview redirection into occupied voxels for slopes and slope corners.
- Keep existing second-slot panels readable and saveable, with recycling, painting and pick support. Zoop still resolves compatible panels into the second slot.
- Keep the selection wheel, area modes, diagonal edges, slope surfaces and placement lock.
- Move the selection-wheel screenshot to the end of the README and mod-manager gallery.

Validation: Release build passed; the distribution assembly no longer contains the removed snap hooks. Interactive gameplay verification remains to be done.
